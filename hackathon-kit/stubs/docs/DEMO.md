# Демо жюри (< 60 секунд)

1. Открыть Activity Map (fixture ok, если RR недоступен).  
2. Клик по подозрительному процессу (shell / payload).  
3. Показать подсветку сети (например `:4444`) и событие на таймлайне.  
4. Incident Summary → Copy.  
5. Одна фраза: «вместо трёх вкладок Runtime Radar — одна картина; time-to-insight < 60 с».

Fallback: режим fixture, честно сказать жюри.
